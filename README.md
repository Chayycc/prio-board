# Prioritization Board — Easy Money · CEO Office

Data PMO prioritization board (single-file, no build).

- **Corporate Impact** — projects (Corporate / BU) ranked by Priority Index
- **Project Priority** — rollup status per project
- **Task Priority** — sub-tasks by Priority / Status / Timeline

Open `index.html` (or the GitHub Pages link). Data auto-saves to the browser (localStorage); use Export/Import (JSON) for backup.
